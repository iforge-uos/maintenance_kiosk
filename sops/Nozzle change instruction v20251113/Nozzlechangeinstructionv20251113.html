Replacing nozzle for Prusa CoreOne

v20251113

Source: https://help.prusa3d.com/guide/how-to-replace-the-prusa-nozzle-core-one_821168#827056

Introduction:

This guide will take you through the Prusa Nozzle replacement on your Prusa CORE One.

Tools needed:

  •  Nozzle replacement tool

   

Preparation

The printer head does not need to be fixed in one position, you can move it anywhere during these processes for space or comfort.

Removing the nozzle

  1. Install the Nozzle Replacement Tool onto the hotend.
  1. Carefully align the CORE One Nozzle Replacement Tool with the hotend's heater block. Make sure you're using the correct variant of the Tool for your hotend setup (with or without a silicone sock).
  2. Gently slide the Nozzle Replacement Tool onto the heater block
  1. Loosen both thumbscrews securing the hotend inside the Nextruder. Do not remove them completely. A few turns are enough.
  2. Use universal wrench to screw the nozzle out (find the right side)
  4. Now, you can easily release the nozzle.

Replacing nozzle

  1. Insert the new nozzle, screw to secure it in place
  2. Use a universal wrench to tighten it
  3. Tighten thumb screws
  4. Remove the nozzle changing tool

Test

Load filament to test if the nozzle can extrude correctly; it may need more purging than usual after a replacement.

Done!
